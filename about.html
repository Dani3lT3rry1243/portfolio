I'm a student focused on Windows desktop application development, building with C# in Visual Studio. Outside of coursework, I run a Debian server at home that I administer entirely from the command line provisioning it, keeping it patched, and using it as the base for whatever I'm building next.

The current focus is tying it together with virtualization spinning up virtual environments to test, isolate, and deploy services without having to physicaly connect it each time.
